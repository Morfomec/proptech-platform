# PropTech Platform

A property rental marketplace and management platform.

## Project Goals

- Property and unit management
- Rental listing creation and discovery
- Rental applications and tenancy management
- Rent charge and payment tracking
- AI-assisted rental listing descriptions

## Technology Stack

- Backend: Django and Django REST Framework
- Frontend: React and TypeScript
- Database: PostgreSQL
